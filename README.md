I'm a **Junior Full Stack Developer** passionate about building tech solutions that solve real problems. This project is my first complete application built from scratch.

### 🎯 What is this project?

It's a **collaborative task manager** where teams can:

- ✅ Create and assign tasks
- 📊 Track progress through dashboards and charts
- 📅 Organize tasks on a visual board (Kanban) or calendar
- 💬 Comment and collaborate on each task
- 📎 Attach files and images
- 🔔 Receive real-time notifications
- 📥 Export reports to Excel and PDF

---

## 🛠️ Technologies I Used

### Frontend
- **React 19** — Library for building the user interface
- **Vite** — Fast development build tool
- **Tailwind CSS** — For styling and design
- **Recharts** — For interactive charts

### Backend
- **Node.js + Express** — Server and REST API
- **MongoDB** — Database for storing data
- **JWT** — Secure authentication system

### Extra Tools
- **Cloudinary** — For uploading images and files
- **Socket.io** — Real-time notifications
- **ExcelJS + PDFKit** — Report generation
